# Modern Art Gallery

Minisite responsive de dos vistas realizado para la tercera tarea entregable de CSS.

## Páginas

- `index.html`: presentación y mosaico de la galería.
- `location.html`: mapa, dirección e información de visita.

## Características

- Maquetación mobile first con puntos de ruptura para tableta y escritorio.
- HTML semántico y navegación accesible con teclado.
- Estados hover y focus en botones y enlaces.
- Recursos gráficos exportados del archivo de Figma proporcionado.
- Iconos sociales y favicon en SVG.
- Tipografías Big Shoulders Display y Outfit.

## Uso local

Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor web estático.
